# ブルベクエスト北海道 － 北海道と青森のブルベを走るファミコン風ゲーム

ブラウザだけで遊べる、ファミコン風のロードバイク（ブルベ）ゲーム。
2026年のAJ北海道・ランドヌール札幌・AJたまがわ（青森）のブルベ日程で、4月から10月までの1シーズンを1週ずつ過ごします。
コンビニで買い物をするたびに時間が減り、ちゃんと補給しないと走れなくなります。

- インストール不要・1ファイル・外部送信なし（セーブはブラウザの localStorage）
- スマホ縦持ちを基準にした1画面レイアウト。キーボードでも操作可

## 遊び方

- 紹介ページ: <https://pikaring.github.io/brevet-quest/>
- 本体: <https://pikaring.github.io/brevet-quest/app/>

ローカルでは `app/index.html` を開くだけ。

| 操作 | 内容 |
|---|---|
| ↑↓ / Z・Enter / X・Esc | 選ぶ / 決定 / 戻る |
| ゆっくり・ふつう・がんばる（1・2・3） | ペース。がんばるは体力と気力を大きく使い、気力が尽きると選べない |
| 食べる（E） | ポケットの補給食を走りながら食べる |
| ×1・×2・×4（F） | 早送り |
| メニュー（Esc） | 防寒着・雨具の着脱、充電、仮眠、リタイア |

## ゲームの中身

- **性格診断**: 最初に6問。7タイプ（スプリンター・鉄の心・峠ハンター・夜型・グルメ・ムードメーカー・準備の鬼）で巡航・登坂・持久力・気力・眠気・食事の効果・トラブル率などが変わる
- **シーズン**: 毎週、ブルベ・ヒルクライム・グラベル・ファンライド・シクロクロスへの出場、トレーニング、残業、休養、友達とのカフェライドから選ぶ。疲労がたまると体力の上限が下がる
- **ブルベ 26本**: AJ北海道12本＋ランドヌール札幌11本＋AJたまがわ（青森）3本（200〜1000km）。開催日・スタート地点・時刻・経由地は主催者の2026年の大会ページから
- **スタート前のトラブル**: サイコンが起動しない、補給食・充電ケーブル・ボトル・筆記用具・サドルバッグの忘れ物、車検でベルがない、軽装、前夜祭の飲みすぎ、Di2の電池切れ、クリートのゆるみ、スローパンク、寝坊、ライトの台座忘れ（作者のブログの実話から）
- **ヒルクライム・グラベル・シクロクロス**: ペースは「頑張る・もっと頑張る・すごく頑張る」の3段階。すごく頑張ると距離の半分で体力が尽きるので、体力を見ながら配分する。グラベルは路面の抵抗で速度が落ちる。時間の進みはゆっくり（ブルベに戻ると元の速さ）
- **体温と風邪**: 体温50がちょうどいい。低すぎる状態が続くと低体温症、高すぎると熱中症でDNF。雨具なしで濡れたり体を冷やしたりすると、ライドのあとに風邪をひいて翌週は自転車に乗れない。
- **PBP 2027（開発中）**: 本編は2026年シーズンの終わりに「来年はPBPだ！（原作開発中）」で終わる。最終ステージのPBP 2027（ランブイエ発着1,220km・制限90時間）は、テストモードから約400kmずつ3ステージで遊べる（ステータスは引き継ぎ）。タイトルの「体験版：2027年シーズン（仮）」は、PBPを完走するまでのストーリーを本編のセーブと別に遊べる。2027年の日程は未発表のため、作者がPBPを目指した2023年のAJ北海道・R札幌の日程（AJ北海道の2023年リザルトとR札幌の開催ページで確認）を2027年の同じ週末に置いた仮の日程（発表済みのAJたまがわは2027年の日程）。2026年11月の函館から（所持金5万円、おこづかい月6万円）。トレーニングのローラー練には室内の機材（三本ローラー2.5万円・フィットネスバイク3.5万円・スマートトレーナー11万円、効果は8割・6割・10割）が必要で、峠練とロング練は外を走る。12〜3月はスパイクタイヤ（前後3万円、高級品6万円は横すべりで転びにくい）がないと外を走れず、市の体育館（1回500円）でも運動できる。運動しない週は体重が増える。1月にはYK2の冬ヒルクライム（Stravaセグメント）と東川のアイスブルベ（R札幌）、2月には凍った大沼をファットバイクで渡るガイドツアーも。冬は背景が雪景色になる。6月27日までにSRをそろえ、出発までに旅費55万円を貯めて（残業は1回2.5万円・疲労+35。疲れがたまると体調を崩して翌週寝込む）、8月22日のPBP 2027（3ステージ、2023年のブログの出来事入り）へ。作者が走った函館200・トトロ300・様似400・宗谷岬600・きのこの山300・函館300・トカプチ朝駆400はブログの記録から、それ以外のコースは推定。SRが取れなかったりPBPで完走できなかったりしたら、2027年の4月からやり直せる。2027年シーズン（資格ブルベ・本登録・旅費）の仕組みも入っているが、AJ北海道とR札幌の2027年日程の発表待ち
- **走行**: 体力・満腹・気力・体温・眠気・ライト・スマホの電池。坂・向かい風・追い風・雨・夜。重い人は上りが不利で向かい風は少し楽
- **PCのコンビニ**: 1つ買うごとに1分。イートインで座って食べると体力も回復。揚げ物は体重が増える。何か買わないと通過証明にならない
- **食堂**: 朝・昼・晩。町の食堂／遠回りの絶品（臨時休業あり）／ファストフード（混雑あり）
- **トラブル**: パンク（急ぐ・丁寧・待つ）、ミスコース、寝落ち、寒さ、鹿、電池切れ、ハンガーノック
- **宿と仮眠**: 600km以上は宿を予約するか、仮眠で済ますか。22時以降は眠気が上がり続け、限界を超えると落車
- **仲間**: 14人の架空の仲間（道南・道北・道東・青森に2人ずつ、道央に6人）。住んでいる地域のブルベに出てきて、地元でしか会えない人もいる。PCでトレインに誘われることも。助けると友情が上がり、トレインを組んだり助けてくれたりする。ペース変更や寄り道で離れるときは事前に確認がある
- **連戦**: 後志300→ウニタラコ200、岩木山200→北へ600のように、同じ週の後日のブルベへゴールからそのまま出られる
- **機材**: 5種のバイク、ライト・ウェア・雨具、コンポ・カーボンパーツ・DHバー。車検はBRM/AJ規定（400km以上は前照灯2灯・ヘルメット尾灯）
- **SR**: 1シーズンで200・300・400・600kmを完走すればスーパーランドヌール

URLの末尾に `#test` を付けて開くと、日付に関係なく全コースを走れるテストモードがタイトルに出ます。

## 開発メモ

- ゲーム本体のソースは `src/brevet-quest.html`。`python3 tools/build_app.py src/brevet-quest.html app/index.html` で `app/index.html` を作る

## データについて

- 日程: [AJ北海道](https://ajhokkaido.jp/)、[ランドヌール札幌 2026年開催BRM](https://randonneurssapporo.net/brmr%EF%BD%8D/2026brm/)、[AJたまがわ 2026年開催BRM](https://ajtamagawa.org/2026brm/)（津軽200・五能線300・奥入瀬十和田400は公式キューシートのコントロールと距離）、道内のイベント情報
- 函館200・函館300・長万部400・北トカプチ200・摩周湖1000・五能線300は作者のブログ [PikaCycling](https://pikacycling.hateblo.jp/) の走行記をもとにしています。宗谷岬600・積丹400・薄野200・新十津川200・岩木山200にも走行記のエピソードを入れています
- それ以外のPCの位置・店・標高、イベントの距離・参加費、宿・食事の値段はゲーム用の推定です。実際に走るときは主催者のキューシートを使ってください
- 装備の規定: [BRM/AJ規定](https://www.audax-japan.org/brevet/brm/brm-part-regulation/)

## ファイル

```
index.html        紹介ページ
app/index.html    ゲーム本体（1ファイル。フォントは Google Fonts の DotGothic16）
assets/           アイコン・OGP画像・スクリーンショット・紹介ページのCSS
assets/goods.json 紹介ページの道具欄の商品情報（画像・価格）
tools/fetch_goods.py         Amazon Creators API で goods.json を取り直す
.github/workflows/goods.yml  毎日 03:00 JST に goods.json を更新（Secrets: CREATORS_CLIENT_ID / CREATORS_CLIENT_SECRET）
```

紹介ページの道具欄は Amazon アソシエイトのリンクです（Ride on QC と共通）。
